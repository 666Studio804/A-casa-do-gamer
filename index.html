🔥 COMO ATIVAR MULTIPLAYER REAL (FUNCIONA 100% NO GITHUB PAGES)

Seu site está em MODO DEMO até você configurar (só você vê). Para virar multiplayer real onde TODOS veem:

  1. Vá em supabase.com > Sign Up grátis > New Project > Nome: a-casa-do-gamer > senha qualquer > Create
  2. Espera 2 min criar > Menu lateral SQL Editor > New Query > Cole isso e clica RUN:
    create table games (id uuid default gen_random_uuid() primary key, name text, description text, category text, file_ext text, size text, rating text, downloads int default 0, icon_data text, banner_data text, author text, created_at timestamp default now());
    alter table games enable row level security;
    create policy "public" on games for all using (true) with check (true);
  3. Menu Project Settings > API > Copie Project URL e anon public key
  4. Neste arquivo index.html procure linha 300 onde tem:
    const SUPABASE_URL = "SUA_URL_AQUI"
    e const SUPABASE_KEY = "SUA_KEY_AQUI"
    Substitua pelos seus e faça commit no GitHub!
  5. Pronto! Agora multiplayer real global! 🌐

Por que Supabase e não Firebase? Supabase é mais simples, grátis, sem cartão, e funciona melhor no GitHub Pages. 500MB grátis.

Dica: Para arquivos .EXE/.APK grandes, ative Storage no Supabase (Bucket public). No código atual, ícone e banner já vão para o banco como base64 (funciona até 2MB por imagem). Para jogos grandes, use link externo ou Storage.
